# -
Создание консольной программы на Python для нахождения произведения матриц N×N с вводом/выводом через консоль и файл, кэшированием вычислений, резервным копированием и восстановлением кэша
### Структура проекта

```text

│
├── src/
│   ├── main.py
│   ├── matrix.py
│   ├── cache.py
│   └── backup.py
│
├── cache/
│   └── matrix_cache.json
│
├── backups/
│
├── docs/
```

### Функциональные требования

1. Ввод матриц через консоль.
2. Ввод матриц из файла.
3. Умножение матриц N×N.
4. Вывод результата в консоль.
5. Сохранение результата в файл.
6. Кэширование вычислений.
7. Резервное копирование кэша.
8. Восстановление кэша из резервной копии.
9. Обработка ошибок ввода.

### Алгоритм кэширования

```python
key = str(matrix_a) + str(matrix_b)

if key in cache:
    return cache[key]
else:
    result = multiply(matrix_a, matrix_b)
    cache[key] = result
    save_cache()
```

### Алгоритм резервного копирования

```text
1. Проверить наличие cache.json
2. Создать папку backups
3. Скопировать cache.json
4. Добавить timestamp в имя файла
5. Сохранить резервную копию
```

Пример:

```text
backups/cache_2026_10_28_120000.json
```

### Алгоритм восстановления

```text
1. Выбрать резервную копию
2. Проверить целостность файла
3. Заменить текущий cache.json
4. Перезапустить приложение
```
