# -
Создание консольной программы на Python для нахождения произведения матриц N×N с вводом/выводом через консоль и файл, кэшированием вычислений, резервным копированием и восстановлением кэша
# N x N Matrix Multiplication

Python console application for multiplying square matrices.

## Features

- console input;
- file input;
- console output;
- file output;
- calculation cache;
- backup system;
- cache recovery.

## Run

python main.py
